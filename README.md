# СЕКРЕТНЫЙ ТЕРМИНАЛ — ARG-квест (SPA)

Один файл `index.html`: HTML + CSS + чистый JS, без внешних зависимостей (шрифты, звуки и иконки — системные или нарисованы CSS). Открывается двойным кликом, работает офлайн.

## Быстрый старт

1. Звук уже лежит в папке `audio/` — можно открыть `index.html` и сразу всё протестировать:

   | Файл | Что это | Формат | Длительность |
   | --- | --- | --- | --- |
   | `audio/secret_tape.m4a` | запись для кодовой фразы «тайна скрыта внутри дома» (на кассете будет `???`) | AAC | 2:14 |
   | `audio/track_1.m4a` | трек «#1 моя большая тайна» | AAC | 0:34 |
   | `audio/track_2.mp3` | трек «#2 скрыта от глаз» | MP3 320k | 1:59 |
   | `audio/track_3.mp3` | трек «#3 что у меня внутри» | MP3 128k | 0:59 |
   | `audio/track_4.m4a` | трек «#4 пока дома» | AAC | 0:34 |

   Это настоящие записи, а не демо-тоны. Заменить их своими — см. раздел «Свои аудио».
   Это демо-записи (синтезированные тоны), чтобы всё работало сразу — замените их своими файлами, пути указаны в `ARG_CONFIG`.
2. Фото зацепок уже лежат рядом с `index.html`: `clue_1.jpg`, `clue_2.jpg`, `clue_3.jpg` — это скан-копии газетных вырезок 2048×2048 (пути — в `ARG_CONFIG.caseFiles.files`). Заменить можно своими файлами.
   Кассета нарисована целиком на CSS, картинка для неё не нужна.

   > **Почему JPEG, а не PNG.** Исходники `clue_1.png`…`clue_3.png` (с альфа-каналом, по 1.4–2.3 МБ) сохранены рядом **без изменений** — это ваши оригиналы. Сайт показывает JPG-версии: те же пиксели и тот же чёрный фон, но в 7–8 раз легче (0.78 МБ вместо 5.74 МБ на все три). Тяжёлый PNG с альфой браузер декодирует построчно — картинка «проявлялась» сверху вниз прямо на глазах. JPEG декодируется целиком и появляется сразу.
   > Если JPG не загрузится (например, файл потерялся при копировании), сайт автоматически подставит исходный PNG — зацепка всё равно откроется.
2. Откройте `index.html` в браузере.
3. Введите в поисковую строку:
   - `тайна скрыта внутри дома` → окно с магнитофоном;
   - `архив` → проводник с «Архивным делом номер 3»;
   - `файлы дела` → папка «Файлы дела»;
   - **название песни** (например `#2 скрыта от глаз`, `2 скрыта от глаз`, `скрыта от глаз`, `моя большая тайна`, `пока дома`) → сразу открывается магнитофон с этим треком (загружен, но не играет — жмите PLAY);
   - `зацепка 1` / `зацепка 2` / `зацепка 3` → открывается окно с этой зацепкой (дальше — лупа).
4. Кнопка **ПУСК** на панели задач открывает меню → **Файлы дела** (и «Поиск» для возврата в главное меню).

Пока файлов нет, интерфейс всё равно работает: магнитофон и архив открываются, вместо аудио в статусе появится «НЕТ СИГНАЛА».

## Конфигурация

Весь «сюжетный» конфиг лежит в начале `<script>` — объект `ARG_CONFIG`:

```js
const ARG_CONFIG = {
  phrases: {
    player:  ['тайна скрыта внутри дома'],  // можно перечислить варианты
    archive: ['архив']
  },
  assets: {
    audio:  'audio/secret_tape.wav',  // запись по умолчанию
    secret: 'audio/secret_tape.wav'   // отдельная запись для кодовой фразы (кассета «???»)
  },
  caseFiles: {                           // папка ПУСК → Файлы дела
    phrases: ['файлы дела', 'файлы', 'дело'],
    files: [
      { id: 'track-1', kind: 'audio', title: '#1 моя большая тайна', audio: 'audio/track_1.wav' },
      // ... track-2, track-3, track-4
      { id: 'clue-1', kind: 'image', title: 'зацепка 1', image: 'clue_1.png' },
      { id: 'clue-2', kind: 'image', title: 'зацепка 2', image: 'clue_2.png' },
      { id: 'clue-3', kind: 'image', title: 'зацепка 3', image: 'clue_3.png' }
    ]
  },
  messages: { notFound, denied, empty },
  behavior: { attemptsBeforeDenied, volume, sfx }
};
```

Особенности:
- ввод нормализуется — регистр, `ё/е`, лишние пробелы и пунктуация не важны («Тайна скрыта, внутри дома!» сработает);
- `behavior.attemptsBeforeDenied` — после N неудачных попыток вместо «ИНФОРМАЦИЯ НЕ НАЙДЕНА» показывается «СТРОГО СЕКРЕТНО. ДОСТУП ЗАПРЕЩЕН»;
- `behavior.sfx: false` отключает синтезированные системные звуки (WebAudio). Все эффекты рисуются на WebAudio — внешних файлов не нужно:
  - `SFX.deckPress` — сухой стук клавиши PLAY/PAUSE;
  - `SFX.deckStart` — лента пошла (гул мотора + щелчок);
  - `SFX.deckStop` — лента встала (щелчок механизма);
  - `SFX.deckKnob` — тихий треск потенциометра громкости;
  - `SFX.errorOpen` — двухтоновый «пинг» системного диалога ошибки;
  - `SFX.errorClose` — отклик при закрытии диалога;
  - плюс общие `click`, `ok`, `error`, `denied`, `tape`;
- названия файлов из `caseFiles.files` работают как поисковый запрос автоматически — `#`, нумерацию и пунктуацию при сравнении игнорируем, поэтому `3 что у меня внутри`, `что у меня внутри` и `#3 что у меня внутри` находят один и тот же трек;
- пункт файла с `kind: 'audio'` по клику открывает магнитофон и **загружает** трек (путь из `audio`), но НЕ запускает его — воспроизведение стартует только по кнопке PLAY (на дисплее горит `PLAY · НАЗВАНИЕ`); `kind: 'image'` открывает **своё отдельное окно** с этой картинкой (окна `win-clue-1/2/3`);
- закрытие магнитофона, открытого из папки, возвращает в папку; закрытие магнитофона, открытого поиском, — в главное меню.

## Сюжетные тексты

Впишите текст в пустые контейнеры в разметке (`white-space: pre-wrap` сохраняет переносы строк):

```html
<div id="archiveCaseBody"></div>      <!-- «Архивное дело номер 3» -->
```

## Отладка из консоли (F12 → Console)

| Команда | Действие |
| --- | --- |
| `argDebug.openPlayer()` | открыть магнитофон в обход пароля |
| `argDebug.openArchive()` | открыть архив в обход пароля |
| `argDebug.openDocument()` | сразу открыть «Архивное дело №3» |
| `argDebug.openCaseFiles()` | открыть папку «Файлы дела» |
| `argDebug.openCaseFile(id)` | открыть файл папки: `track-1`…`track-4`, `clue-1`…`clue-3` |
| `argDebug.openClue(id)` | открыть окно зацепки напрямую |
| `argDebug.openClue(id)` | открыть окно зацепки: `clue-1`, `clue-2`, `clue-3` |
| `argDebug.setAudio(url)` | подменить аудио на лету |
| `argDebug.setVolume(0..100)` | громкость |
| `argDebug.eject()` | сбросить ленту (кассета остаётся в приёмнике) |
| `argDebug.search('архив')` | прогнать строку через логику поиска |
| `argDebug.showError('ТЕКСТ')` | показать произвольный диалог ошибки |
| `argDebug.closeAll()` | закрыть всё, вернуться в главное меню |
| `argDebug.config` | живой объект конфигурации |
| `argDebug.help()` | напомнить список команд |

Пути можно менять без перезагрузки:

```js
argDebug.config.assets.audio = 'audio/test_2.mp3';
argDebug.setAudio(argDebug.config.assets.audio);
```

## Как расширять

- **Новый файл в папке «Файлы дела»:** допишите объект в `ARG_CONFIG.caseFiles.files` — название, статусбар и поиск по названию подхватятся сами (`kind: 'audio'` или `'image'`).
- **Свои фото зацепок:** картинки показываются как есть (без искажений) в квадратной рамке `object-fit: contain` — пропорции не искажаются, ничего не обрезается. Чтобы заменить, положите свои файлы рядом с `index.html` и поправьте пути в `ARG_CONFIG.caseFiles.files`.
- **Чтобы картинка открывалась мгновенно:** кладите рядом не тяжёлые PNG с альфой, а JPEG (или лёгкий PNG без прозрачности). В разметке у `<img>` зацепки указан `data-src="clue_1.jpg"` и `data-fallback="clue_1.png"` — показывается JPG, при ошибке автоматически подставляется PNG. Картинка грузится лениво (не тянет 5 МБ при старте страницы), а после загрузки вызывается `img.decode()` — браузер раскодирует её заранее, и в окне она появляется целиком, а не «сверху вниз». Пока файл грузится, в рамке висит надпись «ИДЁТ ЗАГРУЗКА…».
- **Лупа на зацепках:** наведите курсор на изображение — появится круглая линза 2.5×, которая следует за мышью и показывает ровно тот фрагмент, который под курсором. На телефоне — коснитесь и держите. С клавиатуры: `Tab` к картинке, стрелки двигают линзу, `Esc` убирает её.
- **Свои аудио:** замените файлы в папке `audio/` и поправьте пути в `ARG_CONFIG` — формат подойдёт любой, который понимает браузер (mp3/ogg/wav).
- **Новый секретный экран:** добавьте фразу в `ARG_CONFIG.phrases`, создайте `<section class="window" data-window>` с уникальным `id`, зарегистрируйте его в `WM.register(new DesktopWindow(...))` рядом с `W.*`, добавьте ветку в обработчик `#search-form` и метод в `Screens`. Кнопка на панели задач появится автоматически.
- **Несколько фраз на один экран:** просто добавьте строки в массив (`player: ['фраза один', 'фраза два']`).
- **Другая последовательность сюжета:** `Screens` — единственное место, где описаны переходы; `onClose` окон вызывайте через `close({ silent: true })`, чтобы не получить петлю возврата в меню.

## Форматы аудио

Поддерживаются все форматы, которые понимает браузер: **mp3, m4a (AAC), wav, ogg, aac, opus, webm, flac**.
Для `.m4a` сервер отдаёт MIME-тип `audio/mp4` — воспроизведение проверено и работает.

**Запасной файл.** В `ARG_CONFIG.assets` есть поле `fallback` (сейчас пустое — все файлы на месте):

```js
assets: {
  audio:    'audio/secret_tape.m4a',   // основной файл
  secret:   'audio/secret_tape.m4a',   // запись для кодовой фразы
  fallback: ''                         // запасной (если основной не читается)
}
```

Если основной файл не найдётся или окажется битым, магнитофон сам подставит запасной и продолжит
играть (надпись «НЕТ СИГНАЛА» при этом не появится). Удобно, пока вы меняете формат записей.

## Заметки

- Кнопка «✕» у главного окна `search.exe` намеренно «заблокирована» (окно системы): она трясёт окно и издаёт сигнал.
- Меню «Пуск» закрывается повторным кликом по кнопке, кликом вне меню, клавишей `Esc` или выбором пункта.
- Пока нет файлов `audio/track_*.wav`, при клике на трек магнитофон откроется и покажет «НЕТ СИГНАЛА» — интерфейс не ломается.
- Закрытие окна магнитофона (крестиком или `Esc`) **автоматически останавливает воспроизведение** и перематывает ленту в начало.
- Ни один трек не стартует сам: ни при выборе файла из папки, ни при вводе названия песни, ни при вводе кодовой фразы — только по кнопке PLAY (или клику по самой кассете).
- Панель задач всегда на экране: `position: fixed` + `bottom: 0`, высота экрана берётся из `visualViewport` (CSS-переменная `--app-h`), плюс JS-страховка `keepTaskbarVisible()`, которая возвращает панель на место при ресайзе, смене ориентации или если вьюпорт «прыгнул» (адресная строка на мобильных).
- `prefers-reduced-motion` уважается: анимации отключаются.
- Анимации вставки кассеты нет: кассета всегда стоит в приёмнике. Бумажки с названием на кассете тоже нет — название выводится только на зелёном ЖК-дисплее.
- При воспроизведении круглые ролики кассеты крутятся (левая — 1.15 с, правая — 1.6 с), при паузе останавливаются.
- Кодовая фраза «тайна скрыта внутри дома» открывает отдельную кассету `???` (`assets.secret`) — не путать с треками из папки.
- Окна перетаскиваются за заголовок, `Esc` закрывает верхнее служебное окно.
